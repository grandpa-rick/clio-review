## 1. Theorem as printed (Thm 4)

K finite, nilpotency class ≤ 2. Base T² = BZ².
- δ couples: ∃ commuting pair in Out K (band ρ) with no commuting lift pair in Aut K
  (equivalently [A,B] ≠ 0 in Inn K / ((σ−1)+(τ−1))Inn K).
- [g] couples: ∃ inner band β: Z² → Inn K with lifts k, k′ and [k,k′] ≠ 1 in Z(K) = H²(T²; Z(K)).

Claim: δ couples ⇒ [g] couples. Strict: K = D4 (order 8) has [g] ≠ 0, δ ≡ 0.

Proof = Lemma 3 (δ couples ⇒ K nonabelian; any K) + Lemma 2 (K class ≤ 2 nonabelian ⇒ [g] couples).

## 2. Where class ≤ 2 enters

Only in Lemma 2 (⇐): taking any noncommuting k, k′, class ≤ 2 puts [k,k′] in Z(K), so
(k̄, k̄′) is a band. That's the only use. §2 also uses "Inn K abelian" so δ sits in ordinary
abelian H², but the coupling predicate never needs that (see M1).

## 3. Verdict on the boundary: ARTEFACT. The real boundary is nilpotency.

(a) **Proof extends to every nilpotent K.** Let c be the class and γ_c the last nontrivial
lower-central term. Then γ_c = [γ_{c−1}, K] is generated by commutators [x,y], and γ_c ⊆ Z(K).
So some [x,y] ≠ 1 is central, which means (x̄, ȳ) commute in Inn K, so it's a band with
[g] = [x,y] ≠ 0. For **any** K, [k,k′] ∈ Z(K) ⟺ k̄, k̄′ commute in Inn K. So the
"commuting-in-Inn caveat" in §7 is just the definition of an inner band, and the central-end
formula is defined for every K. (Z) is always a central extension with abelian kernel, and its
coefficients are always trivial. For nonabelian Inn K, the δ-end is Giraud's nonabelian
obstruction. On T² that reduces to "no commuting lift pair", which is well defined and computable.
So Thm 4 holds verbatim for all finite nilpotent K.

(b) **It fails for non-nilpotent K.** K = Dih(C3²) = C3² ⋊ C2 (order 18, centreless):
Aut = C3² ⋊ GL(2,3) (order 432), Inn ≅ K (order 18), Out ≅ PGL(2,3) ≅ S4.
The normal V4 ⊂ PGL(2,3) lifts to Q8 ⊂ SL(2,3). A lift of an Out element is (v, ±g), and
lifts of commuting V4 elements always anticommute. So δ couples, with 12 unordered Out pairs
computed. Z(K) = 1, so [g] ≡ 0. The corner (δ ≠ 0, [g] = 0) is occupied. Controls: S3 and A4
(centreless, cyclic Out) do not δ-couple.

(c) **Computation** (script above). The printed cross-tab reproduces exactly: D4, Q8, Heis(F3),
M16, C4⋊C4 have δ no / [g] yes; D4×C2 has δ yes (30 pairs); Q8×C2 has δ yes (54 pairs);
C4 and C2² are trivial on both ends. (Σ)-split is confirmed for D4, Q8, M16, C4⋊C4.
Heis(F3) was not checked (|Out| = 48 is beyond the brute-force section search; δ = 0 is
consistent with it). Class ≥ 3 nilpotent groups tested: D16, SD16, Q16, D32, SD32, Q32,
D16×C2, Q16×C2, SD16×C2, C8⋊C4 (r = 3, 7), C3≀C3 (order 81), D16×C4, SD16×C4, D16×C2×C2.
All have [g] couples = TRUE (forced by (a)) and δ couples = FALSE. So there is no violation,
and SD16/D16 are not an artefact in the sense of failing. Caveat: none of these δ-couples, so
at class ≥ 3 the extended theorem is (so far) vacuous in small orders. It's an open question
whether any class-≥3 p-group δ-couples. The D4×C2 mechanism (central automorphisms via
Hom(K, Z(K))) is the natural place to look.

(d) **D4 converse witness: CONFIRMED.** |Aut| = 8, |Inn| = 4, |Out| = 2, (Σ) splits, δ ≡ 0,
[r,s] = r² ≠ 1 central. An explicit outer involution section: r ↦ r⁻¹, s ↦ rs
(not inner: c_s is r ↦ r⁻¹, s ↦ s; c_rs is r ↦ r⁻¹, s ↦ r²s).

## 4. Issues

MUST
- **M1.** §6 says class ≤ 2 is "used exactly once and essentially". §7 says it is "the natural
  maximal domain". Both are false. By 3(a) the theorem holds for all nilpotent K. Restate it
  for nilpotent K, or keep class ≤ 2 and drop the maximality and essentiality claims.
- **M2.** The cross-tab rows for SD16 and D16 read "[g] couples: (nonab.)" and "δ: — /
  outside domain". Both ends are well defined and computable there. [g] couples = yes (for D16:
  [r,s] = r² is not central, but [r²,s] = r⁴ ≠ 1 is; in general by 3(a)), and δ couples = no. Fill
  in the values.
- **M3.** Name the true boundary. The implication fails for non-nilpotent K; the witness is
  Dih(C3²), order 18. The "structural cause" paragraph ("(Z) splits only for abelian K") is a
  nilpotency fact. It is false for centreless K, where (Z) splits trivially.

SHOULD
- **S1.** Grade and headline. Once 3(a) is in, "[g] couples" ⟺ "K nonabelian" for nilpotent K.
  So the theorem is "δ couples ⇒ K nonabelian", which is Lemma 3, and that is elementary. The
  phrase "forced correlation (B)" oversells it. Say plainly that the central end detects
  nonabelianness, and that the substance is in which groups δ-couple (the Aut-structure question).
- **S2.** Remark 1 says that for one gerbe the central stage is reached only after
  strictification succeeds. Then within a single gerbe, (δ ≠ 0, [g] defined) cannot happen by
  construction. Make explicit that Thm 4 is a statement about the group K (existence of bands at
  each end), not about one gerbe.
- **S3.** In the D4 strictness proof, "rs ∉ {1, r², s, r²s} ⊂ Aut D4" uses D4-element symbols
  for automorphisms. Give the automorphism explicitly (r ↦ r⁻¹, s ↦ rs).
- **S4.** The "Heis(F3) (Σ) splits" claim is not independently confirmed here. Cite how it was
  checked (Aut = C3² ⋊ GL(2,3) is the standard description).
- **S5.** Open lead to offer MacBeth: find a class-≥3 nilpotent K that δ-couples (none among 16
  tested). Without one, the class-≥3 extension is true but has no witness.
